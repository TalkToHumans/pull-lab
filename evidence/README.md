# Evidence

Public and secondhand evidence about a buyer situation: posts, comments, reviews, job ads, community threads. It comes from people you haven't talked to.

It sharpens the case study (who, the trigger, which options people try and how they fail) and tells [lead-gen](../.claude/skills/lead-gen/SKILL.md) where to look. **It never counts as a call, a buyer step or proof.** Only conversations and purchases do.

## What goes where

| Evidence | Where |
|---|---|
| Someone you talked to | [gtm/sales.md](../gtm/README.md), and [deals/](../deals/README.md) if it's a live opportunity |
| One public item about a buyer situation | here, as an entry in that situation's file |
| Advice from an operator or advisor (not buyer behavior) | here, in `advice.md` |

## Files

One file per buyer situation, named after the situation, not a version number: `bears-short-on-food-before-hibernation.md`. Say at the top which case study version it backs, or that it's no longer current.

## Entry format

```markdown
### YYYY-MM-DD · [Source](link) · [role or company type]

- Signal: need | urgency | option-that-failed
- Quote: "[their words, short]"
- Why it matters: [one line]
```
